> 為 `mini-taiwan-info` 的「飛航」主題分頁準備資料源盤點。
> Worker：plan-art repo。產出日期：2026-06-04。

---

## 0. 一句話結論

`plan-art` 的軌跡資料是**「短期樣本 + 完整 metadata」**，能直接做：
**(A)** 即時/近期樣本下的「機場結構」「航司／機型 mix」「最熱航線」「跨境去向」「時段分佈」。
做不了：**長期年/月趨勢**（樣本只有 7–47 天），需配合民航局/桃機官方統計補齊（已盤點，見 §5）。

---

## 1. 資料源結構說明

### 1.1 來源檔案

`public/tracks/airports/{ICAO}.jsonl` — 每行一筆航班，含完整 metadata + 經緯軌跡。

### 1.2 metadata 欄位（已實測）

```
fr24_id, callsign, flight_number, registration, hex
aircraft_type           ICAO type designator（B77W / A359 / AT76…）
operating_as            實際營運航司 ICAO code（CAL / EVA / MDA…）
painted_as              塗裝航司（多數同 operating_as）
origin_icao, dest_icao  起點/終點 ICAO（可能為空 = FR24 未識別）
dep_time, arr_time      Unix epoch（dep_time 為 0 = 未起飛）
first_seen, last_seen   FR24 雷達首/末次接收
status                  landed / active
trail_points            軌跡點數量
path                    完整 [lat, lon, alt_ft, ts] 陣列（不在統計中使用）
```

### 1.3 ⚠️ 計數慣例

`fetch-tracks` 在「出發機場」與「抵達機場」各寫一筆同樣航班。所以：
- `RCTP.jsonl` 5787 筆 = **起降架次**（landings 2853 + departures 2934）
- 獨立航班 ≈ 2,900（≈ 5787 / 2）
- 後續 KPI 若要「日均班次」**請用獨立航班除以天數**

樣本品質與 brief 中的 4690 略有差異 — 最新資料拉到 2026-04-05，桃園累計到 5787 筆，brief 是較早的數字。

## 4. 衍生指標清單（已可立即計算）

從現有 JSONL 可衍生的 KPI（**已驗證可行**）：

1. **起降架次** — `total` 或 `asDest + asOrigin`
2. **國際/國內分流** — origin/dest 是否皆 `RC*`
3. **跨境去向 Top 國家** — origin/dest 的 ICAO 前綴 → ISO 國碼
4. **Top 航司**（含中文名 + brandColor，已有 DB）
5. **航司類型 mix** — fullservice / lowcost / regional / cargo（airlineDB 有 `type` 欄）
6. **Top 機型**（含中文/英文名稱、座位數，已有 DB）
7. **機型類別 mix** — widebody / narrowbody / regional / prop / bizjet / heli（aircraftDB 有 `category`）
8. **理論座位提供量** — Σ(seats × flights)，可作為「樣本期間運能」代表（非實際旅客數）
9. **Top 航線（雙向）** — `origin->dest` 計數
10. **時段分佈（24 小時 / 7 日）** — `first_seen` UTC+8 換算
11. **航班 status** — landed / active 比例（即時感）

無法做（需官方統計）：
- 實際旅客人數（座位 × 平均載客率才能估算）
- 月/年趨勢
- 載貨量、貨運比例
- 準點率、誤點分佈
- 航空公司市場占有率（樣本航司分佈 ≠ 市占率）

### 6.2 ViewA / ViewB section 結構建議

#### ViewA — 「機場全景：誰在飛、飛去哪」（**plan-art 樣本，即時感**）

- **A1. 7 機場切換卡片**
  - icon + 中文名 + 起降架次 + 國際線占比 bar
  - 點擊切換下面圖表
- **A2. 結構雙環圖**
  - 內環：國際/國內/不明 占比
  - 外環：機型類別（widebody / narrowbody / prop）
- **A3. Top 航司排行（橫條，含 brandColor + 中文名）**
- **A4. Top 機型排行（橫條，含座位數註記 → 暗示運能）**
- **A5. Top 10 航線（origin→dest 雙向合併，含里程估算）**
- **A6. 跨境去向地圖**
  - 以該機場為中心放射狀，按國家彙總（plan-art 已有經緯度，用既有 cameraPresets 風格）
- **A7. 24h × 7d 熱力圖**
  - 看尖峰時段（桃園紅眼班集中在 23–01 點）

#### ViewB — 「長期視角：來去台灣的人」（**官方統計，補長期趨勢**）

> 這部分資料**目前 plan-art 沒有**，需從 §5 的桃機 + 民航局 pipeline 拉。優先級看 mini-taiwan-info 上線時程：MVP 可只做 ViewA，ViewB 二期再加。

- **B1. 全國年旅客趨勢（線圖，2018–最新）**
  - 國際 vs 國內 分線
  - 標記疫情低谷（2020–2022）
- **B2. 桃機客運量月度年比較**（2025 vs 2024 vs 2019）
- **B3. 航空公司年度市占率（堆疊柱）**
- **B4. 載客率對照**（plan-art 理論座位 vs 官方實際旅客 → 算估算載客率）
