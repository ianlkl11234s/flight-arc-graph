## 圖例

| 欄位 | 意義 |
|------|------|
| **軌跡數** | 該機場 JSONL 累計航班數（dep + dest 雙向） |
| **主力日期** | done ≥ 50 筆且完成度 ≥ 80%，視覺化效果完整 |
| **其他日期** | done ≥ 5 筆但未達主力，是樞紐連線帶到的副產物 |
| 日期格式 | 月/日，連續日合併為 `M/D-M/D` |

> 「主力日期」可以放心做完整視覺化；「其他日期」會看到資料偏向某一邊（缺另一端機場的航班）
