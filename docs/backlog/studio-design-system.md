## 1. 視覺方向：A 塔台儀表 · 琥珀

ATC 雷達幕的語言。chrome 退成安靜的石墨色，讓夜空光軌當主角。

| Token | 深色底圖 | 淺色底圖 |
|---|---|---|
| 面板底 | `rgba(11,13,15,.62)` + blur 10 | `rgba(248,249,250,.78)` |
| 框線 | `rgba(214,222,230,.16)` 1px | `rgba(18,24,30,.18)` |
| 文字 1/2/3 | `#e7ebee` / `#a2abb3` / `#69727a` | `#10151a` / `#4c555d` / `#7d868e` |
| 控件底 | `rgba(255,255,255,.05)` | `rgba(0,0,0,.04)` |
| **強調色** | **琥珀 `#f2a93b`**（墨色 `#1a1206`） | `#a86200` |
| rail 底 | `rgba(7,9,11,.8)` | `rgba(240,242,244,.85)` |

- **字體**：JetBrains Mono 一套（web font），中文 fallback `PingFang TC` → `Noto Sans TC`
- **字級**：9（眉標）／10／11（正文）／12／14（面板標題）／18／30（圖說機場碼）
- **間距**：2／4／6／8／12／16／24；**圓角**：2（面板與控件，幾乎直角）
- **特徵**：面板對角 8px 琥珀刻度、rail 選中左側 2px 琥珀線、圖說左側 2px 琥珀線、開關與滑桿方角
- **琥珀只用在**：選中、播放中、主要按鈕、目前時刻。不拿來裝飾
- 數值與 class 對照：展示頁 `directions.tpl.html` 的 `.dir-a`

**和 Pulse 規則的兩處刻意偏離**（寫進 spec，避免日後被當成違規修掉）：
1. Pulse 禁止 web font → PlanArt 允許一套（JetBrains Mono）
2. Pulse 禁止用等寬字包中文 → PlanArt 容器字體是 mono 優先、CJK 落到 PingFang；要實測中英混排的字距與行高

## 3. UX 問題清單（依流程）

**進站**
- `LoadingScreen` 是 70 秒的假倒數，和實際進度無關（`LoadingScreen.tsx:4`）→ 改成真實進度，或只放字標加狀態條
- 一進站就展開「選擇／機場」面板，地圖被遮掉一塊 → 預設收起，讓第一眼看到軌跡

**選機場**（最大的問題）
- 桌機版**沒有「單選一座機場」的主入口**：在 SetsPanel 勾任何一座都會進入組合模式（`IRS:1613`、`App.tsx:906`）
- 入口有 7 個、行為各不同：SetsPanel 勾選、預設組合、Atlas popup「加入」、場景預設（藏在收合段落）、Region 按鈕、Stats 面板、手機選單
- 有的會飛鏡頭有的不會；Region 按鈕把日期寫死成 02-18（`App.tsx:2109`），點一次按鈕列就消失（`App.tsx:2097`）
- → 建議統一成：**點擊或搜尋 = 單選並飛過去**；組合是明確的第二步（「加入組合」）

**日期**
- 有兩套月曆（側欄 `CalendarPanel` 和時間軸彈出），完整／部分資料的標示方式不一致
- 點沒資料的日期毫無反應；CalendarPanel 換日期後不會跟著翻月（`IRS:1810`）
- → 只留一套，放在時間軸展開區

**看軌跡（點擊地圖）**
- 單擊航班出現 tooltip，雙擊才進單航班模式，而且**只能到「顯示」面板切回 Stack All 才能退出**；換機場也不會重置（`App.tsx:1490`）
- → 單擊就把航班卡停到右下（R1）；卡片上有「追蹤這班」和「×」；Esc 退出（R7）

**面板與浮層**
- Stats 同時是 rail 分頁和右側浮層，浮層會蓋住右上按鈕和空域卡（`FlightStatsPanel.tsx:901`）
- 「統計」分頁點了其實是開浮層，分頁本身不會亮（`IRS:3162`）
- 進 Capture 會卸載整個 UI，面板裡的狀態被重置

**頂部**
- 機場名、航班數、日期、相機座標出現兩次（標題列和狀態框，`App.tsx:2262`）
- 資料來源切換（航線軌跡／空域快照）一切換會連帶改範圍、天數、透明度、鏡頭，副作用很大卻放在最顯眼的位置
- → 情境資訊收進左下**圖說**（Caption，展示頁已示範），進 Capture 時同一個元件變成影片標題

**入口重複**：Capture 有 3 個入口、3D/2D 散在兩處、月曆兩套、相機座標顯示兩處

**錯誤**：載入失敗和真的沒資料分不出來（`useFlightData.ts:168`）

**註解與程式不符**（順手修）：`App.tsx:653` 對 `:665`、`App.tsx:761` 對 `:771`

## 7. 起降染色（2026-10-02 拍板，排在 P5 之後獨立一輪）

- **新增模式，不取代**：工具列「染色：高度（預設）｜起降」。預設仍是現有高度漸層；`COLOR_THEMES`、機場配色、分析染色都不變
- **判斷依據＝選定的機場**：dest ∈ 選定 → 進場色；origin ∈ 選定 → 離場色
- **組合內互飛（兩端都在選定內）→ 方案 A 沿路漸層**：起點離場色 → 終點進場色
- **沒有選定機場（region 範圍）**：起降染色不可選，提示「先選機場」
- **起降篩選**：組合內航線在「進場」「離場」篩選都會出現
- **光球與拖尾跟著起降色**：每班顏色與播放時刻無關；組合內航線的光球取目前位置在漸層上的顏色；切回高度染色即完全恢復
- 驗收：高度染色模式下 visual-check 與 summary-snapshot 必須和改動前完全相同
