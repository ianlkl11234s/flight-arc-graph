# Flight Arc Data Inventory

## 1. 原始資料欄位（每筆 Flight）

| 欄位 | 類型 | 範例 | 說明 |
|------|------|------|------|
| `fr24_id` | string | `"3a5b7c9d"` | FR24 唯一識別碼 |
| `callsign` | string | `"CI100"` | 航班代號（前 2-3 碼 = 航空公司） |
| `registration` | string | `"B-18218"` | 機體註冊號（可識別個別飛機） |
| `aircraft_type` | string | `"A333"` | ICAO 機型代碼 |
| `origin_icao` | string | `"RCTP"` | 出發地 ICAO（4 碼） |
| `origin_iata` | string | `"TPE"` | 出發地 IATA（3 碼） |
| `dest_icao` | string | `"RJAA"` | 目的地 ICAO |
| `dest_iata` | string | `"NRT"` | 目的地 IATA |
| `dep_time` | number | `1739836200` | 出發時間（Unix 秒） |
| `arr_time` | number | `1739847000` | 到達時間（Unix 秒） |
| `status` | string | `"landed"` | 航班狀態 |
| `trail_points` | number | `142` | 軌跡點數量 |
| `path` | TrailPoint[] | 見下方 | 飛行軌跡 |

### TrailPoint 結構：`[緯度, 經度, 高度(m), Unix timestamp]`

每筆航班有 10~500+ 個軌跡點，每個點包含精確的 4D 座標（3D 空間 + 時間）。

---

## 2. 可直接從原始欄位提取的資訊

### 2A. 時間維度

| 可提取資訊 | 來源欄位 | 說明 |
|-----------|---------|------|
| 飛行時長 | `arr_time - dep_time` | 分鐘/小時 |
| 出發日期 | `dep_time` | 轉台北時區 |
| 出發時段 | `dep_time` | 小時 (0-23) |
| 星期幾 | `dep_time` | 週一~週日 |
| 早/午/晚航班 | `dep_time` | 紅眼/晨間/午間/晚間 |
| 軌跡持續時間 | `path[last][3] - path[0][3]` | 實際軌跡記錄時長 |
| 時間解析度 | `path[i+1][3] - path[i][3]` | 軌跡點間距（秒） |

### 2B. 空間維度

| 可提取資訊 | 來源欄位 | 說明 |
|-----------|---------|------|
| 大圓距離 | `origin` + `dest` 座標 | 起訖點直線距離 |
| 實際飛行距離 | `path` 逐段加總 | 沿軌跡的實際距離 |
| 最高巡航高度 | `max(path[][2])` | 公尺 |
| 巡航高度帶 | `path` 中段高度 | 避開爬升/下降段 |
| 飛行方向 | origin → dest 方位角 | 東飛/西飛/南北 |
| 軌跡 bounding box | `path` min/max lat/lng | 航線空間範圍 |
| 跨日期線 | `path` 經度展開 | 是否經過 ±180° |

### 2C. 航班身份

| 可提取資訊 | 來源欄位 | 說明 |
|-----------|---------|------|
| 航空公司 | `callsign` 前 2-3 碼 | CI=華航, BR=長榮, JL=日航 |
| 航線 pair | `origin + dest` | e.g. TPE-NRT |
| 國內/國際 | origin/dest ICAO prefix | 都是 RC→ 國內 |
| 來源國家 | `origin_icao` prefix | ICAO prefix → 國家 |
| 目的國家 | `dest_icao` prefix | 同上 |
| 個別飛機 | `registration` | 同一架飛機的多次飛行 |
| 機型大類 | `aircraft_type` | 可分類窄體/廣體/螺旋槳 |

### 2D. 軌跡衍生（從 path[] 計算）

| 可提取資訊 | 計算方式 | 說明 |
|-----------|---------|------|
| 即時速度 | 相鄰兩點距離/時間差 | km/h，每個點都有 |
| 爬升/下降率 | 相鄰兩點高度差/時間差 | m/s 或 ft/min |
| 平均速度 | 總距離/總時間 | km/h |
| 最高速度 | max(逐段速度) | km/h |
| 爬升剖面 | 高度 vs 時間曲線 | 起飛到巡航的爬升形狀 |
| 下降剖面 | 高度 vs 時間曲線 | 巡航到落地的下降形狀 |
| 轉彎角度 | 相鄰三點方位角變化 | 航路轉折 |
| 飛行階段 | 高度變化率分段 | 爬升/巡航/下降/地面 |

## 3. 跨航班聚合統計（目前已實作 ✅ / 尚未實作 ⬜）

### 3A. 流量分析

| 統計 | 狀態 | 說明 |
|------|------|------|
| 每日出發/到達數 | ✅ | 按機場、按日期 |
| 24 小時分佈 | ✅ | 按機場的小時直方圖 |
| 機場航班量排名 | ✅ | 全台灣機場比較 |
| 星期分佈 | ⬜ | 週一到週日的航班量差異 |
| 尖峰/離峰時段 | ⬜ | 從 hourly 找出尖峰小時 |
| 日間趨勢 | ⬜ | 多天資料的日趨勢（量是增是減） |

### 3B. 航線網路

| 統計 | 狀態 | 說明 |
|------|------|------|
| 目的地統計 | ✅ | 按機場出發到哪 |
| 國家分組 | ✅ | ICAO prefix 分組 |
| 可達目的地 | ✅ | All Taiwan 出發能到哪 |
| 國內航線 | ✅ | 台灣機場間互飛 |
| 獨佔航線 | ⬜ | 只有一家航空公司飛的航線 |
| 航線頻率 | ⬜ | 同航線每天幾班 |
| 航線距離分佈 | ⬜ | 短/中/長程航線數量 |
| OD matrix | ⬜ | 完整的起訖矩陣（可做 chord diagram） |

### 3C. 航空公司與機隊

| 統計 | 狀態 | 說明 |
|------|------|------|
| 航空公司排名 | ✅ | callsign 前綴 |
| 機型排名 | ✅ | aircraft_type |
| 飛行時間分佈 | ✅ | <1h / 1-3h / 3-6h / 6h+ |
| 航空公司 × 航線 | ⬜ | 哪家飛哪些航線 |
| 航空公司 × 機型 | ⬜ | 哪家用哪些機型 |
| 機型 × 航線距離 | ⬜ | 窄體飛短程、廣體飛遠程 |
| 同機體追蹤 | ⬜ | registration 追蹤同一架飛機的行程鏈 |
| 航空公司市佔率 | ⬜ | 按機場的航空公司 pie chart |

### 3D. 軌跡分析

| 統計 | 狀態 | 說明 |
|------|------|------|
| 巡航高度分佈 | ⬜ | 所有航班的巡航高度直方圖 |
| 速度剖面 | ⬜ | 平均速度 vs 飛行階段 |
| 航線幾何差異 | ⬜ | 同一 OD 不同航班的路徑差異 |
| 空域密度 | ⬜ | 哪些區域航跡最密集 |
| 高度層使用 | ⬜ | FL250/FL350 等的使用率 |
| 爬升/下降時間 | ⬜ | 從地面到巡航高度的耗時 |

## 5. 潛在的視覺化方向

### A. 地圖上的空間視覺化

| 構想 | 資料需求 | 說明 |
|------|---------|------|
| **空域熱力圖** | path[][] 所有軌跡點 | 將所有航跡點 rasterize 成 heatmap |
| **高度層切片** | path[][2] 高度 | 只顯示特定高度的航跡（如 FL350） |
| **速度渲染** | path 逐段速度 | 軌跡顏色映射到速度 |
| **OD 弦圖 on map** | origin/dest pairs | 起訖機場之間的弧線寬度 = 航班數 |
| **航線走廊** | 同 OD 多條 path 疊加 | 看出固定航路 vs 偏離 |
| **時間播放密度** | path + timestamp | 不同時段的空域擁擠度動態 |

### B. 統計圖表（目前 sidebar / 可獨立頁面）

| 構想 | 資料需求 | 說明 |
|------|---------|------|
| **Chord Diagram** | OD matrix | 機場間航班量的圓形連線圖 |
| **Sankey Flow** | 國家 → 機場 → 航空公司 | 多層級流量圖 |
| **高度剖面疊圖** | 同航線多航班 path | 多航班的爬升/巡航/下降 overlay |
| **時鐘圖 (Clock)** | hourly stats | 24 小時圓形分佈 |
| **機隊氣泡圖** | airline × aircraft × count | 氣泡大小=航班數 |
| **航線距離 vs 時間散佈** | distance + duration | 看出效率差異 |
| **同機追蹤甘特圖** | registration + dep/arr time | 一架飛機一天飛了哪些航段 |
| **Small Multiples** | 14 機場各一個迷你圖 | 並排比較各機場的 hourly pattern |

### C. 互動體驗

| 構想 | 資料需求 | 說明 |
|------|---------|------|
| **航班時間軸回放** | path + timestamp | 滑桿控制，看飛機在空中的分佈變化 |
| **篩選聯動** | 所有欄位 | 點航空公司 → 只顯示該公司航線 |
| **航線比較** | 同 OD 的多航班 | 比較不同航班的高度/速度/路徑 |
| **機場 360° 視角** | camera presets + flights | 從跑道視角看航班起降 |
