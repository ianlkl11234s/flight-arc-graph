優點

  • 維護最輕：靜態頁產生器（scripts/seo/）加一段 HTML，不碰 App／Timeline，無互斥、無 Esc 行為要處理。

缺點

  • 已在地圖裡的使用者看不到；要回到靜態頁才有入口。
